# Hook ledger

Every line we change in an upstream (Metrolist) file is listed here, with the reason. Everything
else we build lives under `turtle/` or in new files. CI (`turtle/scripts/check-hooks.sh`) fails a PR
that edits an upstream path without also updating this file.

90 on 23 Nov 2026 by the product owner so Turtle can ship under its own identity (roadmap step 5b):
its own Android app id and versionCode (#63), in-app updaters on both platforms that check Turtle's
releases (#64, #65), its own Windows taskbar identity (#66) and its own desktop data folder with a
one-time copy of the old data (#67 to #70). Earlier raises: from 30 on
