## Mechanics notes

HOME SLATE (production since Mar 2025). Per request a bandit predicts a content-type distribution p over music/podcast/audiobook from context (time of day, day of week, device, user and content embeddings). The slate is then filled greedily item by item, each pick scoring relevance minus a KL penalty between the slate's running type histogram and p. Action = the distribution; reward = a stream started from Home; exploration = epsilon-greedy. Online vs a 90-day control: podcast impression-to-stream +36.6%, overall +3.93%. BaRT (2018, Home). Preference model is a factorization machine over user x item x explanation features; reward is "was this impression streamed". Browse model: a vertical pass samples shelf_k from a policy over shelf candidate list L_k, a horizontal pass samples card_j from within-shelf set M_k, each conditioned on the user still being aware. Training is counterfactual maximum likelihood on logged propensities, so a candidate policy is scored offline by importance reweighting. SPDD (KDD 2026) bolts an auxiliary target onto any greedy or generative slate builder with no retraining. At each position it scores relevance + lambda * that item's contribution to the auxiliary objective (novelty, diversity, category share). lambda is a dual variable updated after every pick from progress made, gap remaining and positions left: it rises when the list falls behind, falls when on track. One step-size knob; cost linear in list length x candidate count. Online: auxiliary stream share +5.44% vs +3.60% for fixed weights, skip rate +0.16% vs +0.42%. GLIDE (podcasts). 1B LLM. Input = recent listening + long-term taste injected as soft tokens projected from dense user embeddings (keeps prompts short) + a control token selecting non-habitual-familiar vs non-habitual-unfamiliar. Beam search emits semantic-ID token sequences mapped to catalogue items; it runs as an extra candidate generator into the existing ranker, not a replacement. 21-day Home A/B, ~20M impressions/cell: non-habitual listening +5.4%, new-show discovery +14.3%. IMPATIENT BANDITS: a Bayesian filter fuses partial and complete outcomes into a belief about the ~2-month repeat-engagement reward, so the bandit acts long before the horizon closes. ALGOTORIAL: editor fixes a listener need plus a content hypothesis, builds an oversized pool using search filters and per-track playlist performance; algorithms then select and order per user; cover art swaps to that listener's top-affinity artist.

## Spotify weaknesses

- **Spotify's own experiment shows personalisation narrows each listener** — Treatment recommendations based on music history raised podcast streams 28.90% but 'decreased the average individual-level diversity of podcast streams by 11.51%' while raising aggregate diversity 5.96%. Spotify names an 'engagement-diversity trade-off' producing consumption 'homogenous within and diverse across users'. (https://research.atspotify.com/publications/the-engagement-diversity-connection-evidence-from-a-field-experiment-on-spotify)
- **BaRT's ranking model was never defined to promote diversity** — Spotify's own limitations slide for the Home bandit lists, verbatim: 'ranking model not defined to promote diversity'. Diversity was not a term in the objective that ranked Home shelves and cards; it arrives only later, via the 2025 calibration work and SPDD's auxiliary targets. (https://static1.squarespace.com/static/5ae0d0b48ab7227d232c2bea/t/5ba85dac7817f764cdda68f4/1537760712983/bart_recsys.pdf)
- **Spotify openly doubts its own reward approximates satisfaction** — The same limitations slide asks of BaRT: 'maximizes our defined reward, does it approximate user satisfaction?' The 2025 Home calibration work has the same shape — its reward is whether a user streamed from Home, which the post itself calls 'a short-term engagement signal'. (https://research.atspotify.com/2025/9/calibrated-recommendations-with-contextual-bandits-on-spotify-homepage)
- **Exploration is confined to a candidate set, not the catalogue** — BaRT's stated limitation: 'exploration-exploitation over a candidate set not the full item set'. Whatever upstream retrieval excludes can never be explored, so the bandit's apparent open-mindedness is bounded by a pipeline stage that is not itself exploring. (https://static1.squarespace.com/static/5ae0d0b48ab7227d232c2bea/t/5ba85dac7817f764cdda68f4/1537760712983/bart_recsys.pdf)
- **Natural-language taste profiles cannot handle negation or short-term change** — Textual User Taste ships to millions of users, yet Spotify reports limits 'around negation and short-term temporal adaptation'. Telling it what you do not want, or that your taste shifted this week, is the weak spot — and the measured lift is small: MRR +0.6%, search NDCG@7 +2.2%. (https://research.atspotify.com/publications/textual-user-taste-natural-language-user-context)
- **The conversational agent degrades past four turns and loses earlier constraints** — Quality 'declined as conversations grew longer, with the steepest drop beyond four turns'. Named failures: wrong tool-call arguments reordered playlist tracks, and over-summarizing dropped earlier constraints. Content Refinement and Instruction Retention scored weakest of the five capabilities. (https://research.atspotify.com/2026/9/bootstrapping-conversational-recommendation-agents-at-spotify-synthetic-data-generation-and-self-improvement-loops)
- **Offline metrics missed staleness, language mismatch and low diversity** — During GLIDE development Spotify found offline metrics alone missed stale recommendations, language mismatches and low diversity, forcing human evaluation and LLM judges. The LLM-judge interest-alignment score moved 0.44 to 0.91 across iterations, so early models scored below half. (https://research.atspotify.com/2026/8/from-models-to-products-llms-for-recommendation-at-spotify-scale)
- **Spotify's own LLM evaluation is measurably biased** — Intent-Description Anchoring Bias (RecSys 2026) shows how an intent is described to an LLM judge systematically skews ratings, and that small wording changes meaningfully shift results. A companion 2026 paper finds better LLM reasoning traces do not reliably yield better recommendations. (https://research.atspotify.com/2026/9/contexts-conversations-and-connections-spotify-research-at-recsys-2026)
- **Discovery Mode puts a paid promotion signal inside personalized recommendations** — Artists and labels flag priority songs, adding a signal that 'increases the likelihood of the selected songs being recommended', applied to personalized playlists and to Radio & Autoplay, with Spotify taking 'a percentage of revenue generated on those select streams'. Recommendations are not purely taste-driven. (https://artists.spotify.com/en/discovery-mode)
- **The headline AI features are Premium-only and market-gated** — DJ launched for Premium in the US and Canada and, as of the page's 18 Mar 2026 update, is available in English and Spanish only. AI Playlist launched 7 Apr 2024 as a Premium beta on Android and iOS in the UK and Australia only, and refuses non-music prompts. (https://newsroom.spotify.com/2024-04-07/spotify-premium-users-can-now-turn-any-idea-into-a-personalized-playlist-with-ai-playlist/)
- **Spotify's own 2026 result undercuts the sequence-model complexity it ships** — 'On four of the five benchmarks, at least one pairwise model scores higher than both Transformer reproductions.' PCTM beats eSASRec on MovieLens-1M (0.1815 vs 0.1739 NDCG@10). Much published sequential-recommendation gain may be benchmark artefact, not modelling. (https://research.atspotify.com/2026/10/do-sequential-recommendation-benchmarks-require-higher-order-sequence-modelling)
